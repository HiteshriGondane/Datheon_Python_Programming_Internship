# Hangman Worlds — Python Console Game

## Project Overview
Hangman Worlds is a terminal-based word-guessing game developed using Python. The player must guess a hidden word one letter at a time within a limited number of attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Maximum of 6 incorrect attempts
- Display of guessed letters
- ASCII hangman drawing updated after incorrect guesses
- Win and lose messages

## Technologies Used
- Python 3
- `random` module
- Standard Python libraries

## How to Run
1. Install Python 3.
2. Download `hangman.py` from this folder.
3. Open a terminal in the downloaded file's directory.
4. Run:

```bash
python hangman.py
```
